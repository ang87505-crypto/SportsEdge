## Integration and integrity repair

Both branches touched the manual stock backtest workflow. The combined workflow keeps the corporate-action option
off by default, runs the existing data audit first, runs reconciliation only when explicitly selected, and uploads
derived outputs after all producers finish. The public artifact includes the reconciliation alongside results,
audit and forward JSON. Raw action pages and private, identifier-bearing output are excluded.

A concrete defect was reproduced before repair: changing a dividend in an archived page changed classifications,
but `reconcile` accepted it and reported the same legacy archive digest. That digest binds declared page hashes,
not the page contents. The new verifier compares every complete page to its stored hash, checks page counts and
terminal pagination, and rejects invalid/failed chunk shapes before calculation. A separate full canonical digest
also binds ticker aliases and query metadata. The old digest remains for comparison with immutable #201 results.
Integrity hashes detect changed inputs; they do not attest that the provider supplied every action or establish
when a historical trader could have seen it.

New synthetic tests reproduce the corruption refusal and exercise incomplete pagination, failed chunks, alias
binding, public redaction, separate CLI outputs and refusal to overwrite existing evidence. The upstream 22 tests
continue to pass. The original recorded `reconciliation.json` is unchanged and is not retroactively described as
page-verified: its raw source pages are not in this repository.
